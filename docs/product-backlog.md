# Product Backlog — Magic Elixir Perfum

## Épica 1: Gestión de Usuarios y Acceso

### Feature 1.1: Autenticación
- HU-01: Como empleado, quiero iniciar sesión con correo y contraseña, para acceder solo a mis funciones.
- HU-02: Como administrador, quiero crear y desactivar cuentas de empleados, para controlar el acceso.

### Feature 1.2: Datos del cliente
- HU-03: Como vendedor, quiero registrar clientes con teléfono y dirección, para no pedir los datos nuevamente.

## Épica 2: Catálogo de Productos

### Feature 2.1: Administración de perfumes
- HU-04: Como administrador, quiero registrar perfumes con marca, mililitros y precio, para tener el catálogo completo.
- HU-05: Como administrador, quiero actualizar precios, para reflejar cambios del proveedor.

### Feature 2.2: Categorización
- HU-06: Como administrador, quiero clasificar perfumes en 4 categorías, para que coincida con Instagram.

## Épica 3: Control de Inventario

### Feature 3.1: Control de existencias
- HU-07: Como administrador, quiero ver cantidad disponible de cada perfume, para no ofrecer agotados.
- HU-08: Como vendedor, quiero que el sistema avise si no hay stock, para no cerrar ventas falsas.

## Épica 4: Gestión de Pedidos y Pagos

### Feature 4.1: Registro de pedidos
- HU-09: Como vendedor, quiero crear un pedido con cliente y productos, para dejar registrado.
- HU-10: Como vendedor, quiero agregar varios perfumes a un pedido, para armar la compra completa.

### Feature 4.2: Cálculo y pagos
- HU-11: Como vendedor, quiero que calcule el total, para cotizar sin errores.
- HU-12: Como vendedor, quiero registrar el método de pago, para saber cómo se pagó.

## Épica 5: Logística y Envíos

### Feature 5.1: Despacho nacional
- HU-13: Como vendedor, quiero registrar envío con guía y transportadora, para informar al cliente.
- HU-14: Como vendedor, quiero actualizar estado del envío, para responder sin llamar.

## Épica 6: Abastecimiento y Proveedores

### Feature 6.1: Gestión de proveedores
- HU-15: Como administrador, quiero registrar proveedores, para tener a quién llamar.
- HU-16: Como administrador, quiero crear órdenes de compra, para dejar constancia.

## Épica 7: Post-Venta, Devoluciones y Garantías

### Feature 7.1: Devoluciones
- HU-17: Como vendedor, quiero que valide que la solicitud esté dentro de 30 días, para aplicar política sin discutir.
- HU-18: Como administrador, quiero aprobar o rechazar devoluciones, para decidir cada caso.
- HU-19: Como administrador, quiero calcular reembolso según motivo, para aplicar regla igual a todos.

### Feature 7.2: Garantías
- HU-20: Como administrador, quiero registrar garantía con fecha y meses de cobertura, para saber si está cubierto.
- HU-21: Como vendedor, quiero consultar si garantía sigue vigente, para responder al cliente.

## Épica 8: Reportes e Indicadores

### Feature 8.1: Reportes de ventas
- HU-22: Como administrador, quiero ver total vendido en rango de fechas, para saber cómo le fue.
- HU-23: Como administrador, quiero ver perfumes más vendidos, para saber qué reponer.
- HU-24: Como administrador, quiero ver ventas por canal, para decidir dónde invertir.
